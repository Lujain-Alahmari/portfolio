# Lujain.OS — Star Edition ✦

Personal portfolio in HTML, CSS and vanilla JavaScript.

## Run
Unzip and open `index.html` in your browser. No dependencies required.

## Features
- Pastel blue retro Windows-inspired desktop + editorial hero
- Star motifs (no hearts)
- Window open/close, hover, scrolling, and navigation sparkle animations
- Draggable windows on desktop, keyboard Escape to close
- Responsive mobile version and prefers-reduced-motion accessibility
- About, Projects, Experience, Skills and Contact
- Contact email preserved: `alahmari1lujain@gmail.com`

## Edit
Modify `index.html` for homepage, `script.js` for window content and interactions, and `styles.css` for styling and effects.

## Live clock
The Windows-inspired taskbar time automatically updates from the visitor's own device every second, displaying the local time with AM/PM. No timezone is hard-coded.
