# ✦ Lujain.OS — Personal Portfolio

A little desktop of my world.

Welcome to **Lujain.OS**, my interactive portfolio inspired by classic desktop interfaces, modern editorial layouts, and minimalist web design. Built with a soft pastel-blue palette and star-inspired details, it brings together my work in **AI engineering, NLP, and software development**.

## ✦ About Me

I'm **Lujain Mesfer**, a Computer Science graduate from King Khalid University and an AI Engineering Bootcamp alumna at Olo Academy. I enjoy exploring practical AI applications, especially multilingual retrieval and retrieval-augmented generation (RAG), and building technology that makes information easier to use.

## ✦ Features

- **Retro desktop experience:** Windows-inspired interface with interactive icons and application-style windows.
- **Smooth animations:** animated window transitions, navigation sparkles, hover effects, and scroll reveals.
- **Draggable windows:** move the windows around on desktop using a mouse or pen.
- **Live device clock:** the taskbar clock updates every second using the visitor's local device time (12-hour format, AM/PM).
- **Responsive layout:** works across desktop and mobile screen sizes.
- **Accessible motion:** honors the browser/device's `prefers-reduced-motion` setting.
- **No frameworks required:** built with HTML, CSS, and vanilla JavaScript.

## ✦ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Lujain-Alahmari/portfolio.git
   ```

2. Open the `portfolio` folder.
3. Open `index.html` in your browser. No installation or build step is needed.

> If you have named your GitHub repository something other than `portfolio`, update the clone URL accordingly.

## ✦ Project Structure

```text
portfolio/
├── index.html    # Main page and desktop layout
├── styles.css    # Colors, responsive styles, and animation effects
├── script.js     # Window interactions, portfolio content, and live clock
└── README.md     # Project documentation
```

## ✦ Publish with GitHub Pages

1. Upload the four files to the root of a **public** GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. Once deployment completes, your portfolio will be available at a URL like `https://lujain-alahmari.github.io/portfolio/` (if your repository is named `portfolio`).
